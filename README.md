# Toxic Neon Graffiti for Millennium

Тема для Steam / Millennium в стиле Toxic Neon Graffiti с верхней панелью переключения вкладок:

- Магазин
- Библиотека
- Сообщество
- Профиль
- Друзья / чат

Цель:
- сделать визуально концепт Deadlock + graffiti + neon
- сохранить стандартную навигацию Steam
- добавить верхний таббар, который активирует уже существующие элементы интерфейса или безопасные Steam URL

## Структура

```
Millennium/
├── resource/
│   ├── scripts/
```

## Установка

1. Откройте папку Steam skins:
   `C:\Program Files (x86)\Steam\skins`
2. Создайте или откройте папку `Millennium`.
3. Скопируйте содержимое этого репозитория внутрь `Millennium`.
4. В Steam выберите интерфейс `Millennium`:
   `Steam > Настройки > Интерфейс > Оболочка`
5. Перезапустите Steam.

## Что делает тема

- тёмный фон с кислотным зелёным и неоновым розовым акцентом
- граффити-эффекты и грязные мазки
- верхняя непрерывная навигация в стиле Deadlock / toxic neon
- активная вкладка максимально выделена glow-эффектом
- при наведении — лёгкая анимация и подсветка
- JS пытается привязаться к реальным элементам Steam UI и активировать их, а не ломает стандартную навигацию

## Поддержка / доработка

Тема можно дорабатывать под текущий интерфейс Steam и Millennium: 
- цвета
- размеры верхней панели
- выбор нужных вкладок
- дополнительные эффекты шрифта, граффити, шумов и контуров
